# AI エージェント振り分けルール

ChatGPT・Gemini・Claude を Claude Code から使い分けるためのルール。
該当する指示を受けたら、以下のツールへ委譲すること。

## 名指しされたとき

| 言われ方 | 使うツール |
| --- | --- |
| 「gemini」「Gemini で」 | `mcp__gemini-cli__ask-gemini` |
| 「gpt」「ChatGPT」「codex」 | `mcp__codex-cli__codex` |
| 「3つとも」「全部に聞いて」「比較して」 | `mcp__multi-llm__ask_all` |

## 内容で振り分けるとき（名指しがない場合）

| 内容 | 使うツール | 理由 |
| --- | --- | --- |
| 「調べて」「検索して」「最新情報」「ニュース」 | `mcp__gemini-cli__ask-gemini` | Gemini CLI は Google 検索を併用できる |
| 「文章を書いて」「作成して」「たたき台」「言い換えて」 | `mcp__codex-cli__codex` | 文章生成を Codex 側に寄せる |
| 「アイデア出し」「ブレスト」 | `mcp__gemini-cli__brainstorm` | 発想支援用のツールが用意されている |
| 設計判断・技術選定でセカンドオピニオンが欲しい | `mcp__multi-llm__ask_all` | 3モデルの回答を並べて比較できる |

## 委譲するときの原則

- **文脈を渡す。** 各モデルはこの会話もリポジトリの中身も見ていない。関連するコード・
  制約・技術スタックをプロンプトに含めてから投げること。含めないと一般論しか返らない。
- **鵜呑みにしない。** 返ってきた内容はこのリポジトリの実際のコードと突き合わせて検証し、
  食い違う点は指摘する。そのまま貼り付けて回答にしない。
- **出典を示す。** どのモデルの発言かを明示する。複数に聞いた場合は
  一致点（確度が高い）と相違点（判断が必要）を分けて示すこと。
- **連鎖させる。** 「gemini で調べて、その結果を踏まえて gpt で書いて」のような指示では、
  前段の出力を後段のプロンプトに明示的に埋め込んでから渡す。

## 使い分けの前提

- `gemini-cli` / `codex-cli` は各 CLI のログイン（サブスクリプション）を使う。API キーは不要。
- `multi-llm` は各社の **API キー**を使う（`.env.local`）。3モデル並列比較用。
- 未設定のものは呼んでも失敗する。セットアップは `docs/multi-ai-setup.md` を参照。
